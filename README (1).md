# 🎓 Student Performance Analysis – Power BI Dashboard

An interactive Power BI project that analyzes student academic performance using attendance, study hours, gender, and parental education.

## 🛠️ Tools
Power BI • DAX • Power Query • Python (Pandas) • SQL

## 📊 Dataset
6,000 student records (after removing 15 duplicates) with columns: `student_id`, `student_name`, `age`, `gender`, `parental_education`, `study_hours_per_day`, `attendance_percentage`, `math_marks`, `reading_marks`, `writing_marks`, `total_marks`, `percentage`, `result`.

## 🎯 KPI Cards
Total Students • Average Marks • Highest Marks • Average Attendance • Pass Percentage • Average Study Hours

## 📈 Dashboard Pages
1. Student Overview
2. Academic Performance
3. Attendance Dashboard
4. Gender Analysis
5. Study Hours Dashboard
6. Student Ranking

Slicers: Gender, Result, Parental Education, Age

## 🚀 How to Run
1. Clone the repository
2. Open `power_bi/Student_Performance_Dashboard.pbix` in Power BI Desktop
3. Update the data source path if prompted, then click **Refresh**
